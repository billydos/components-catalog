# Changelog

## v0.0.3

Изменения с v0.0.2 (коммит `8b0a3fa`, 2026-10-11) по коммит `d69da3d` (2026-10-11).

### Добавлено

- CLI: позиционный аргумент `all` субкоманды `catalog list` — печатает все найденные записи, перебирая страницы поиска в пределах сервисного потолка `limit`; контракт пагинации service/REST (`limit <= 200`) не изменился. `all` — единственный допустимый позиционный аргумент, взаимоисключим с `--limit`/`--offset` (явное `--offset 0` тоже отклоняется).
- Seed: покрытие полевых транзисторов — условия `Usi`/`Uzi` (с `allow_negative`)/`Isi`, единицы `nA` и `mA_per_V`, электрические параметры `IcNach`, `S`, `UziOts`, `UziPor`, `Izut`, `Czi`/`Czs`/`Csi`, `RsiOtk` и предельные `UziMax`, `PsiMax`, `IsiPulseMax`; названия и символы новых сущностей — в бандлах en/ru.

### Изменено

- Каталог параметров: стоковые величины полевых транзисторов получили собственные коды — `PkMax`/`PkPulseMax` стали коллекторными (только биполярные), новые `PsiMax`/`IsiPulseMax` несут стоковые величины, ранее пересекавшиеся по коду `PkMax`. В формате наполнения записям полевых транзисторов вместо `PkMax` требуется `PsiMax`; записи `data/transistors.jsonc` переведены.
- CLI: разбор аргументов переведён с `urfave/cli` на собственный код — реестр команд сам ведёт диспетчеризацию, проверку числа аргументов и поддерево `catalog`. Лексический контракт не изменился: `--` завершает флаги, одиночный `-` — позиционный аргумент (закреплено тестом); из зависимостей ушли `urfave/cli` и транзитивный `text/template`.

### Документация и прочее

- План: примеры записей по классам (`docs/plan/06-examples.md`) сокращены до 2–3 записей на систему и не более десяти на класс — примеры демонстрируют форму записи и различия систем обозначений, а не полноту типов.
- Skill `changelog`: закреплены формат секции версии (`TEMPLATE.md`) и правило диапазона — границы записи только два явных коммита, не `HEAD`.
- Документация (`docs/plan/*`, `docs/class-keys.md`, `docs/fill-format.md`, AGENTS.md) и бандлы en/ru обновлены вслед за расширением seed и изменениями CLI.
- Обновлены отчёты прогонов QA (`qa/reports`).

## v0.0.2

Изменения с v0.0.1 (коммит `fe9712c`, 2026-10-10) по коммиту `df4c746` (2026-10-11).

### Breaking changes

- Удалена система обозначений series и реестр `series_families` из всех слоёв: domain, storage, catalog, importer, REST/CLI, seed, i18n и документация.
  - Версия схемы БД выросла 5 → 7 (series + последующие правки); существующие базы пересоздаются.
  - Прежние series-обозначения стали системой `other`; автодетект для них больше не работает — требуется явный `--system other --kind`.
  - REST-каталог лишился `series_families`; перечисление систем — только `gost/ost/pro/jedec/jis/other`.
  - Поле обозначения `power` удалено как дубль параметра `Pnom`.
  - Формат наполнения: секция `fields` получила необязательные грамматические поля `series`/`dev_number`/`letters` для записей системы `other`; записи в `data/` конвертированы.

### Добавлено

- CLI: команда `version` — печатает версию сборки (в релизах инъектируется через `-ldflags -X`).
- CLI: карточки справки — `help <command>` показывает строку usage с полным набором флагов и опции с описаниями; `help catalog <sub>` — карточку субкоманды, `help catalog` — usage-строки всех субкоманд; общий help дополнен примерами и заметкой о позиции опций.

### Изменено

- CLI: разбор аргументов переведён с самописного парсера на `urfave/cli` v3 (дерево команд и диспетчеризация — библиотека); строгий лексинг флагов, каталог сообщений, локализованные ошибки и коды выхода сохранены байт-в-байт. Изменение поведения на границах: флаг перед субкомандой — теперь явная ошибка вместо тихой потери; отсутствующая/неизвестная субкоманда — специализированные сообщения.
- CLI: текст справки генерируется из реестра команд (раскладка колонок и перенос слов — по локали) вместо монолитного сообщения каталога.

### Исправлено

По итогам аудита CODEREVIEW-03 (находки высокого и среднего приоритета):

- Импорт NDJSON: строка-обёртка `{"catalog":…, "<класс>":…}` больше не обходит гейт смешанного файла `catalog import` (раньше запись молча терялась уже после применения каталога); невалидный JSON-хвост после значения строки — жёсткая ошибка формата.
- Storage: адресная чистка сирот-производителей вместо O(N²) анти-джойна на каждую замену секции (добавлен индекс `device_manufacturers(manufacturer_id)`, схема 6 → 7); COUNT и страница поиска — из одного запроса, без рассинхрона total; батч-чтения по списку id чанкуются; устранена самоблокировка `:memory:`/`MaxOpen=1`.
- Валидация: значения исполнений проходят проверку принадлежности секции; деактивация параметра не ломает инвариант «повторный импорт того же файла — Skipped»; выбор ошибки валидации детерминирован (без зависимости от порядка map).
- Разбор обозначений: корректный машиночитаемый код при явном несовместимом классе и неоднозначном «Ф»; позиции ошибок канонизации при внутренних пробелах; контроль ошибок `Atoi` и ведущих нулей/длины ГОСТ-номеров; убран тихий fallback с сырой кириллической буквой в `gostSubclassCode`.
- Слои и ошибки: `domain` больше не импортирует `internal/i18n` (выделено locale-нейтральное ядро рендера); ошибки открытия БД/DDL/сидирования переведены с сырых литералов на каталог сообщений.
- REST: в контракт DeviceRecord (`api/openapi.yaml`) добавлено описание секции `fields`.
- CI/релизы: actions закреплены по SHA вместо мутируемых тегов; маскировка DSN в выводе дочерних процессов QA; `golang.org/x/sys` зафиксирована в списке зависимостей AGENTS.md и плане.

### Документация и прочее

- План (`docs/plan/*`), `docs/fill-format.md`, `docs/class-keys.md` и README обновлены вслед за удалением series; отчёт CODEREVIEW-03 актуализирован (сняты находки C17/C40).
- Skill `git-commits` переведён на английский.
- Обновлены отчёты прогонов QA (`qa/reports`).
