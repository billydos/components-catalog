# 05. План работ

Оценки относительные (S ≤ недели фокусной работы, M — 2–4, L — больше); главный множитель этапов 1 и 6 — предметная каталогизация и выверка по первоисточникам, не код. Правило гигиены: после каждого пакета — `go build ./... && go vet ./... && gofmt -l .` и `go test ./...`; дословные тексты сообщений — контракт, закреплены тестами дословно (языковая политика — D9: канонический en; до этапа 8.2 тексты формируются по-русски).
