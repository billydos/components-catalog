# Справочник ключей по классам приборов

Сводный перечень возможных ключей и подключей записи наполнения для каждого
класса приборов: системы обозначений, атрибуты, параметры по секциям
(`parameters` / `ratings` / `dimensions`), условия измерения, исполнения,
семейства `series`. Отражает **стартовое наполнение каталога** (сид
`seed/seed.go`, план `docs/plan/03-data-model.md`); каталог — данные (D1) и
может быть расширен секцией `catalog` — действующий реестр всегда смотрите
командой `catalogctl catalog list --db <база>`.

Форма файлов, семантика секций (замена целиком, идемпотентность), единицы
и типичные ошибки — `docs/fill-format.md`; живые примеры записей —
`docs/plan/06-examples.md` и `data/`.

## 1. Общие ключи записи (все классы)

Корень файла: `catalog` (опционально) + секции классов — `transistors`,
`diodes`, `resistors`, `capacitors` (все опциональны). Запись — объект
(либо короткая форма — строка с обозначением):

| Ключ | Обязателен | Смысл |
|------|-----------|-------|
| `name` | да | обозначение без хвостов заказа (мощность/напряжение/ёмкость — исполнениями) |
| `system` | только для `other` | код системы; по умолчанию — автодетект |
| `attributes` | нет | объект «код атрибута → значение» (§2) |
| `parameters` | нет | секция группы `electrical` — список значений (§3) |
| `ratings` | нет | секция группы `limiting`; **у конденсаторов секции нет** |
| `dimensions` | нет | секция группы `dimensional` — список значений (§8) |
| `manufacturers` | нет | список имён производителей |
| `variants` | нет | исполнения (только резисторы и конденсаторы, §9) |
| `analogs` | нет | исходящие ссылки-аналоги: `"ИМЯ"` или `{ "name", "note" }` |

Системы обозначений по классам:

| Класс | Системы (`system`) |
|-------|--------------------|
| `transistor` | `gost`, `pro`, `jedec`, `jis`, `series`, `other` |
| `diode` | `gost`, `pro`, `jedec`, `jis`, `series`, `other` |
| `resistor` | `gost`, `ost`, `series`, `other` |
| `capacitor` | `gost`, `series`, `other` |

Поля разбора (материал, подкласс, номер разработки, семейство) в файле
не задаются — их даёт разбор обозначения.

## 2. Атрибуты (`attributes`)

Объект «код → значение». Типы: `text` — непустая строка; `bool` —
`true`/`false`; `int` — положительное целое (годы); `enum` — значение из
списка. `null` — атрибут не задаётся.

### 2.1. Все классы

| Код | Название | Тип | Примечания |
|-----|----------|-----|-----------|
| `category` | категория прибора | text | для записей, у которых подкласс не кодируется обозначением (`series`, `other`, `jedec`): «выпрямительный», «стабилитрон», «импульсный»… |
| `technology` | технология | text | |
| `package` | корпус | text | |
| `packageMaterial` | материал корпуса | text | |
| `colorMarking` | цветовая маркировка | text | |
| `pinout` | цоколёвка | text | |
| `esdSensitive` | чувствительность к статическому электричеству | bool | |
| `militaryGrade` | приёмка для военного применения | bool | |
| `radiationHardened` | стойкость к ионизирующему излучению | bool | |
| `tu` | технические условия | text | |
| `notes` | примечания | text | |
| `yearFrom` | год начала выпуска | int | правило `year_range` (1949–2100) |
| `yearTo` | год окончания выпуска | int | правило `year_range`; `yearFrom < yearTo` |
| `datasheetUrl` | ссылка на документацию (datasheet) | text | |

### 2.2. Ограниченная применимость

| Код | Название | Тип | Классы |
|-----|----------|-----|--------|
| `structure` | структура (p-n-p / n-p-n, тип канала) | text | транзисторы, диоды |
| `polarized` | полярный (электролитический) | bool | конденсаторы |
| `functionalChar` | функциональная характеристика (закон изменения сопротивления) | enum: `А`, `Б`, `В` | резисторы |

## 3. Форма значения параметра (секции `parameters`, `ratings`, `dimensions`)

Список объектов; порядок списка — порядок значений на карточке:

```jsonc
{ "parameter": "h21e", "min": 50, "max": 350, "Uke": 10, "Ik": 1 }
```

| Подключ | Смысл |
|---------|-------|
| `parameter` | обязательный код параметра каталога |
| `value` | точное значение — для типа `exact` |
| `min`, `max` | границы: `range` — обе; `at_least` — `min` (`max` необязателен); `at_most` — `max` |
| `text` | значение для типов `text`/`enum` |
| прочие ключи | коды условий измерения (число): `Uke`, `Ik`, `temp`, `freq`, … (§10) |

Комбинация условий обязана совпадать с одним из наборов условий параметра
(колонка «Условия» в таблицах ниже): без пометки — обязательное условие,
«опц.» — необязательное, «фикс.» — константа, которую можно опустить.
Повтор параметра с теми же условиями — дубликат (ошибка). Числа
положительны, кроме параметров с пометкой «отрицательные допустимы».

## 7. Конденсаторы

### 7.1. Секция `parameters` («характеристики»)

Секции `ratings` у конденсаторов **нет** — предельные данные отражены
рабочими характеристиками `opTempMin`/`opTempMax`.

| Код | Название | Ед. | Тип | Условия | Примечания |
|-----|----------|-----|-----|---------|-----------|
| `Cnom` | номинальная ёмкость (границы ряда) | пФ | range | — | у электролитических — вариантный |
| `Dop` | допуск | % | at_most | — | |
| `TKE` | температурный коэффициент ёмкости (ТКЕ) | — | enum | — | значения — §7.3 |
| `Unom` | номинальное напряжение | В | exact | — | у электролитических — вариантный |
| `Tgd` | тангенс угла потерь | % | at_most | опц. `temp` | |
| `Iut` | ток утечки | мкА | at_most | `Unom`, опц. `temp` | нормируется на `Unom` варианта |
| `Esr` | эквивалентное последовательное сопротивление | Ом | at_most | `freq` = 0,1 МГц (фикс.) | константу можно опустить |
| `Iripple` | допустимый ток пульсаций | мА | at_most | `freq`, опц. `temp` | электролитические; вариантный |
| `opTempMin` | наименьшая рабочая температура | °C | exact | — | отрицательные допустимы; `temp_pair` |
| `opTempMax` | наибольшая рабочая температура | °C | exact | — | `temp_pair` |
| `Riz` | сопротивление изоляции | Ом | at_least | — | общий с резисторами |

Ёмкость — в пФ (мкФ/нФ переводятся на входе).

### 7.2. Общие предельные данные (справочно)

`TempMin`, `TempMax` (`temp_pair`, `TempMin` — отрицательные допустимы),
`TempJunctionMax`, `Rth` — применимость {транзистор, диод, резистор};
указываются в секции `ratings` соответствующего класса.

### 7.3. Значения enum `TKE`

- нормируемый (линейный), 10⁻⁶/°C: `П100`, `П120`, `П60`, `П33`, `МП0`,
  `М33`, `М47`, `М75`, `М150`, `М220`, `М330`, `М470`, `М750`, `М700`,
  `М1500`, `М1300`, `М2200`;
- ненормируемый (сегнетокерамика), %: `Н10`, `Н20`, `Н30`, `Н50`, `Н70`,
  `Н90`.

Варианты написания (`П100`/`П120`, `М750`/`М700`, `М1500`/`М1300`) —
отдельные допустимые значения.

## 8. Массогабаритные данные (`dimensions`, все классы)

Все параметры — `exact`; связаны правилом формы корпуса
`cap_dimensions_form`: прямоугольный набор (`length`+`width`+`height`),
осевой цилиндрический (`diameter`+`leadLength`), радиальный цилиндрический
(`diameter`+`height`); смешение форм и неполный набор — ошибка. `massMax`
допустим с любым набором.

| Код | Название | Ед. |
|-----|----------|-----|
| `massMax` | масса (наибольшая) | г |
| `length` | длина | мм |
| `width` | ширина | мм |
| `height` | высота | мм |
| `diameter` | диаметр | мм |
| `leadLength` | длина выводов | мм |
| `leadPitch` | шаг выводов | мм |

## 9. Исполнения (`variants`)

Структура варианта: `label` (метка для карточки и фильтров: «160 В»,
«0.125 Вт») + те же секции значений, что у записи (`parameters`,
`ratings`, `dimensions`).

| Класс | Допустимость | Обязательные параметры варианта | Правило |
|-------|--------------|--------------------------------|---------|
| транзисторы, диоды | запрещены | — | — |
| резисторы | допустимы (ряд мощностей) | `Pnom` | `resistor_variant_power`; `Pnom` и метки уникальны в записи |
| конденсаторы | допустимы (матрица «ёмкость × напряжение») | `Unom` + `Cnom` | `cap_variant_matrix`; `Unom` и метки уникальны в записи |

Габариты варианта — согласованным набором формы корпуса (§8). Данные типа
в целом (`TKE`, `Dop`, `Tgd`, `Riz`, полярность, ТУ, годы) — в секциях
самой записи.

## 11. Реестр семейств `series` (стартовый)

Хвост семейств с семантикой «мощность» — номинальная мощность, Вт
(`tail_semantic = power`); у остальных — общий слабый хвост (число и
буквы). Реестр расширяется данными (секция `catalog`, подраздел
`series_families`); обозначение неразобранного семейства — ошибка с
перечнем поддерживаемых.

### 11.1. Транзисторы

| Семейство | Расшифровка | Примеры |
|-----------|-------------|---------|

## 12. Именованные правила валидации

| Код | Семантика | Привязка |
|-----|-----------|----------|
| `year_range` | `yearFrom < yearTo`; диапазон 1949–2100 | атрибуты `yearFrom`/`yearTo` |
| `cap_dimensions_form` | согласованность формы корпуса (§8) | параметры группы `dimensional` |
| `temp_pair` | `TempMin < TempMax` / `opTempMin < opTempMax`, если заданы оба | обе температурные пары |
| `cap_variant_matrix` | вариант конденсатора обязан иметь `Unom`+`Cnom`; габариты — согласованным набором; уникальность `Unom`/метки | класс `capacitor` |
| `resistor_variant_power` | вариант резистора обязан иметь `Pnom`; уникальность `Pnom`/метки | класс `resistor` |
