# Ревью архитектуры против плана

Сплошное чтение кода с отчётом — задача 7.3 `docs/plan/05-work-plan.md`.
Формат отчёта фиксирован этим файлом и обязателен для будущих ревью
(следующие ревью — новые файлы `qa/architecture-review-<дата>.md` по тому
же формату).

## Формат отчёта

1. **Объём и метод** — что прочитано (пакеты/файлы целиком), против каких
   документов плана сверено, что проверено прогонами.
2. **Соответствие решениям D1–D8** — по каждому решению: подтверждение
   местами кода.
3. **Соответствие правилам AGENTS.md** — слои и зависимости, ошибки-значения,
   семантика секций, именование, единицы, переносимость DML, схема без
   миграций.
4. **Замечания** — таблица: №, место (файл:строка), суть, класс
   (дефект/риск/решение), статус (устранено/принято/отложено с билетом).
5. **Выводы** — готовность к релизу, что оставить на следующий цикл.

Отчёт подтверждается прогонами: `go build/vet/gofmt/test`, сценарии
`qa/scenarios.sh`, нагрузочная прикидка — со ссылкой на отчёт прогона.

## 3. Правила AGENTS.md

- **Слои**: направление `domain ← catalog/storage ← service ←
  importer/httpapi/cli` соблюдено; SQL не поднимается выше `storage`
  (проверено чтением всех файлов), разбор форматов не выходит из
  `importer` (REST читает тело записи общим читателем `ReadRecordJSON`),
  бизнес-правил в транспортах нет (валидация — движок каталога,
  единственная точка записи — сервисы, R5).
- **Ошибки**: `*domain.Error{Code,Message}`; коды — константы `domain.Code…`,
  дублирования строк кодов по месту использования не найдено; русские
  тексты закреплены дословно (`domain/errors_test.go`, pin-тесты httpapi/
  cli/importer); CLI-префиксы и REST-модель — на месте.
- **Семантика секций**: `stateMerger` + `sameState` — замена целиком,
  `null` — не менять, `[]` — очистить; Skipped без записи в БД и без
  инкремента ревизий; частичное применение записи исключено (ошибка —
  весь upsert откатывается; importer компенсирует холостые создания).
- **Именование**: коды ошибок/ключей стабильны; DDL — snake_case по
  docs/plan/02; идентификаторы Go — MixedCaps, файлы — snake_case.
- **Единицы**: канонический справочник — данные (`units`); хранение
  каноническое, производные единицы отображения в хранилище отсутствуют
  (вывод канонических — осознанное ограничение v0.1, замечание №6).
- **Переносимость DML**: только `database/sql` + `sql.Named`, булевы —
  0/1, без JSON-функций СУБД; весь DML — в явных транзакциях записи
  (`Tx`), чтения — из пула чтения; SQLite: WAL + busy_timeout + одно
  соединение записи.
- **Схема без миграций**: DDL v0.1 не менялся после фиксации — версия
  схемы 1 корректна, инкремент не требуется.
