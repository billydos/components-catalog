# Консолидированный список новых кодов (предложения пакетов P1–P13d)

Партия: «Справочник по электрическим конденсаторам» (М.: Радио и связь, 1983),
с. 41–525. Источник в каталоге — `cap1983`.

Составлено по разделам «Новые коды» отчётов пакетов `tmp/reports/P1.md` … `P13d.md`.

Статус: все коды — **предложения**; ни один не введён, `catalog-extension.jsonc`
не изменялся, значения величин помещены в `notes` соответствующих записей.

## 1. Новые коды параметров и рейтингов

| Код | Термин | Секция | Тип/единица | Пакеты |
|-----|--------|--------|-------------|--------|
| `Qreact` | реактивная мощность | parameters | exact / var (1 квар = 1000 вар) | P4 |
| `Lnom` | индуктивность | parameters | at_least / uH | P4 |
| `Ithrough` | максимальный проходной ток | ratings | exact / A | P4 |
| `Vimp` | номинальное импульсное напряжение | parameters | exact / V (либо расширить `VPulseMax` на конденсаторы) | P4 |
| `RinsCase` | сопротивление изоляции вывод—корпус | parameters | at_least / ohm | P5 |
| `CnomTotal` | суммарная ёмкость многосекционного конденсатора | parameters | range / pF | P5 |
| `VnomAC` | номинальное напряжение переменного тока | parameters | exact / V | **P5, P10b** |

## Выводы

- 13 пакетов без предложений (P1, P2, P7, P8a, P8b, P9, P11a1, P11a2, P11b,
  P12a, P12b, P12c, P13a); 9 пакетов выдали предложения (P3, P4, P5, P6,
  P10a, P10b, P13b, P13c, P13d).
- Всего уникальных позиций: 21 новый код (разд. 1), 3 расширения `kinds` и
  1 расширение атрибута `sections` (разд. 2), enum-значения `TCC` (разд. 3),
  3 значения `series` для class-keys (разд. 4).
- Повторяющиеся предложения — кандидаты на первоочередное включение в
  `catalog-extension.jsonc`: `VnomAC`, `DeltaC`, `Inom`, а также тройка
  расширений `endurance` / `rotationAngle` / `staticFrictionTorque`.
- Причастные величины до введения кодов хранятся в `notes` записей;
  P13c и P13d правку `catalog-extension.jsonc` не выполняли — правка
  запрещена условиями этих пакетов.
