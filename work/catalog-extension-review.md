# Ревью расширения каталога (work/catalog-extension.jsonc)

Дата: 2026-11-02. Предмет: предложение расширения стартового сида по итогам
анализа сканов справочника. Ревью — против правил именования
(docs/plan/03-data-model.md §6.9, §15 docs/class-keys.md), прецедентов сида
и конвенций классов. Статус: расширение **внедрено** в стартовый сид
(состав — в финальной таблице).

## Решения по кодам

| Предложено | Решение | Обоснование |
|------------|---------|-------------|
| `Z` | принято | международный символ импеданса; обязательное условие `freq` (в герцах) |
| `toleranceMin`/`toleranceMax` | удалено | `Tolerance` переведён на тип `limits` с `allow_negative`: асимметрия −20/+50 % — одна строка `{min:-20, max:50}`; односторонний допуск «+10 %» — строка только с `max`. Два exact-параметра разрушили бы фильтрацию по допуску одним параметром |
| `Tau` | `TauIns` | код обязан называть величину: прецедент `Tauc` (τк коллекторной цепи). τиз — квалификатор-слово ins (изоляция) |
| `Vpeak` | принято, группа `electrical` | см. поправку ниже |
| `fPulse` | принято | строчная `f` — норма символа частоты (`fT`); `Pulse` прописной — квалификатор режима (`VrPulseMax`) |
| `Rdis` | принято | сокращённый квалификатор при R — прецедент `Rth`; полная форма `Rdischarge` также допустима (прецеденты `Rcoil`/`Rcontact`) |
| `DeltaU` | `DeltaV` | правило U→V (§6.9а): советское U всегда передаётся V (`Vf`, `Vz`, `Vce`…); греческое имя + символ — прецедент `AlphaVz` |
| `IPulseMax` | принято | паттерн `I…PulseMax` (`IcPulseMax`, `IfPulseMax`) без электрода; амперы оправданы масштабом импульсных токов (в отличие от мА полупроводников и `Iripple`) |
| `tCharge`/`tDischarge` | принято | строчная `t` + слово с прописной — паттерн `tOperate`/`tRelease`/`tBounce` |
| `tWork`/`tPause` | принято | хорошая пара; `tOn`/`tOff` запрещены: у транзисторов `Ton`/`Toff` — другая величина (время включения/выключения), различие только регистром |
| `tHold` | принято | подтверждено источником: режимный параметр допустимого режима импульсных конденсаторов, часы |
| `NPulseMin` | `endurancePulse` | ресурс в каталоге — именованное семейство `endurance`/`enduranceElec`/`enduranceMech` (словные camelCase, `at_least`, unit NULL, «циклов» — в названии); `N` — не международный символ величины, суффикс `Min` у безразмерного ресурса избыточен |
| unit `Hz` | удалено из расширения | уже в реестре — частота переведена на канонические герцы |
| unit `s` | принято | в реестре только дольные (ps…ms); секунда нужна для τиз и времён режима |

## Поправка к первоначальному ревью: Vpeak и VPulseMax

Первоначально предлагалось переиспользовать код резисторов `VPulseMax`.
Это невозможно структурно: группа — свойство параметра, единое для всех
классов (`limiting` ⇒ пишется только в секцию `ratings`), а у конденсаторов
секция `ratings` закрыта метасхемой (допустимы только
`operatingLife`/`shelfLife`). Поэтому у конденсатора обязан быть собственный
код в группе `electrical` — `Vpeak`, как и предложил сторонний агент.
Именование корректно: свойство-слово со строчной первой при символе V —
прецеденты `Vpickup`/`Vdropout` (реле), `VcoilNom`. Коды `VPulseMax`
(резисторы, ratings) и `Vpeak` (конденсаторы, parameters) — величины разных
секций, сосуществуют.

## Требования к данным (для наполнения по сканам)

1. Единица выбирается по целости значений: база обязана давать целые числа
   (принцип, уже применён к частоте — герцы). Если времена режима в сканах
   целые в мс — единица меняется каталогом данных на `ms` без правки кода;
   дробные секунды не пишем.
2. Условия `freq` — в герцах (`100000`, не `0.1`).
3. Импульсный блок — характеристики секции `parameters` (не ratings).
4. Отображаемые названия новых кодов уже в бандлах en/ru; при добавлении
   новых кодов данными — вносить `param.<код>`/`unit.<код>` в оба бандла.
