## 2. Отклонённые коды

| Код | Причина |
|-----|---------|
| `Vimp` (P4) | **дубль существующего `Vpeak`** («допустимое пиковое напряжение в течение ограниченных интервалов» — это и есть номинальное импульсное Uимп). Значения писать в `Vpeak`. Расширение `VPulseMax` невозможно: его группа `limiting` пишется в `ratings`, у конденсаторов секция закрыта |
| `Inom` (P10b, P13c) | дубль `Ithrough` — слиты в `IthroughMax` |
| `DeltaC` (P6, P10b) | двусмысленный общий код; точная пара `DeltaClife`/`DeltaCshelf` закрывает обе семантики |
| `selfDischarge` (P10b) | физика уже покрыта: `Rins`, `TauIns` (τ=R·C), `Ileak`, `DeltaV`. Если источник нормирует «падение напряжения на X % за Y ч» — это `TauIns` либо заметка |

## 4. Расширения применимости — приняты

- `endurance`, `rotationAngle`, `staticFrictionTorque` → {резистор,
  **конденсатор**} — пишутся в `ratings` конденсатора автоматически
  (закрытость секции — следствие применимости, не белого списка);
- атрибут `sections` → {резистор, конденсатор};
- enum `TCC` + `±50`, `±100`, `±200` (слюдяные), `+(33±30)` (К31-10) —
  дословные группы источника;
- `class-keys` §12.5: серии `ЭТ`, `КПВ`, `КПВМ`.

**Внимание при работе с секцией `catalog`**: `kinds` замещается **целиком** —
в файле наполнения указывайте полный список (`["resistor", "capacitor"]`),
иначе потеряется применимость резисторов.

## 5. Требования к переносу значений из `notes` в новые коды

1. Частоты — в герцах; реактивная мощность — в варах (квар × 1000);
   индуктивность — в микрогенри (мГн/Гн переводятся).
2. Знаковые limits (`AlphaC`, `DeltaClife`, `DeltaCshelf`): симметричный
   ±N — парой `{min: -N, max: N}`; асимметричный и односторонний — дословно
   по источнику.
3. `VacMax`/`Rcoupling` — с обязательным условием `freq`.
4. Отображаемые названия уже в бандлах en/ru; при вводе новых кодов
   данными — ключи вносить в оба бандла одновременно.
