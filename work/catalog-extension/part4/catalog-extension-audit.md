# Отчёт по аудиту сида после слияния part4 — правки и требуемые действия

Дата: 2026-11-26. Предмет: пост-слиянийный аудит стартового сида
(`seed/seed.go`, 246 параметров) — консистентность, именование кодов,
градации значимости. Правки на нашей стороне **внесены** (сид, бандлы
en/ru, пин-тесты, план 03, class-keys, fill-format, файл
`catalog-extension (3).jsonc` синхронизирован). Проверки: build/vet/test
зелёные, `catalog import` вашего файла поверх обновлённого сида —
no-op, действующие данные (`data/transistors.jsonc`) проходят.

## 1. Переименования кодов — требуется применить к вашим данным

Аудит именования по §6.9 выявил 6 отклонений от регламента, введённых
при ревью part4 (наша недоработка — извиняемся за лишний проход).
Действующие определения уже переименованы в сиде; **строки данных в
ваших 284 файлах, ссылающиеся на старые коды, перестанут проходить
валидацию — переименуйте их**:

| Было | Стало | Правило |
|------|-------|---------|
| `VbrCeo` | `Vbrceo` | §6.9в: терминалы + JEDEC-буква — строчные (прецеденты `VceoMax`, `Ices`) |
| `VbrEbo` | `Vbrebo` | то же |
| `Ron` | `ROn` | §6.9б/в: R_(ON) → R+On, режим `On` с прописной (прецедент `RdsOn` — пример самого §6.9б) |
| `tonKey` | `tOnKey` | режим `On`/`Off` с прописной (прецеденты `tOperate`, `VgsOff`, `IdOff`) |
| `toffKey` | `tOffKey` | то же |
| `tonUjt` | `tOnUjt` | то же |

Прочие определения не переименовывались: кадры `Diff`/`Mismatch`/`Ratio`,
`Case`/`Ambient`/`Channel`/`Sub`, `Op`/`Opt`/`Gen`/`Agc`/`Cw`/`Avg` —
оставлены как согласованные классы квалификаторов. Имена отображения
(бандлы) не менялись — только ключи.

## 2. Изменения градаций значимости — на данные не влияют

Пин «первая очередь фильтрации» пересмотрен (43 primary + 42 tertiary,
остальные 154 — secondary по умолчанию):

- **Подняты до primary:** `Pmax` (диоды — симметрия с `PcMax`/`PdMax`/`Pnom`),
  `DF` (симметрия семейства потерь с `Esr`).
- **Опущены до secondary:** `VcerMax` (условный предел при живом
  `VceoMax` primary), `VdSubMax` (парный `VsbMax` — secondary),
  `VggMax` (соседи `VgdMax`/`VgsMax` — secondary), семь кодов семейства
  подобранных пар: `gfsMismatch`, `IdssMismatch`, `VgsOffMismatch`,
  `IdssRatio`, `gfsRatio`, `TCVgsDiff`, `RonMismatch` (выравнивание с
  биполярной стороной `hfeRatio`/`VbeDiff`/…).
- **Поднят до tertiary:** `Ices` (пара к `Icer`: JEDEC-конфигурации s/r).

## 3. Прочие исправления сида

- `TempJunctionMax` — применимость доведена до {транзистор, диод,
  резистор, конденсатор}: план §6.2/§6.4 требует, `Rth` уже имел
  конденсатор (рассинхрон part3).
- `allow_negative` добавлен: `VgsQuadratic` (участок квадратичности у
  полевых с управляющим переходом — отрицательные Uзи),
  `TCVgsDiff`/`TCVbeDiff`/`TCVcbDiff`/`TCIbDiff` (температурные уходы
  разностей знакопеременны). **Действие для данных:** если в ваших
  строках встречались отрицательные значения этих величин, которые
  ранее не проходили валидацию — теперь они допустимы; положительные
  строки не затронуты.
- Документация синхронизирована: план §3 (в т.ч. `V_per_us`), §5.1,
  §6.1/§6.2/§6.8/§6.9г/§6.9ж; fill-format §10 (6 единиц part3/part4);
  class-keys §4.1.

## 4. Ваш порядок действий

1. Переименовать 6 кодов из раздела 1 в файлах данных.
2. Повторить сводный прогон `catalog import --dry-run` по всем 284
   файлам: «0 Issues» должен сохраниться.
3. Доставить файлы данных в репозиторий — итоговый сводный импорт
   выполним на нашей стороне.

Определения-эталон для сверки — обновлённый `catalog-extension
(3).jsonc` в этом каталоге (идентичен сиду, импорт поверх сида — no-op)
либо `catalogctl catalog export` на свежей базе.
