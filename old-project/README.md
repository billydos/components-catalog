# SovietTransistorsDatabase (Go) - справочник советских транзисторов

Консольная утилита на Go для ведения локальной базы справочника советских полупроводниковых приборов. Хранит структуру обозначения (ГОСТ 10862-64), электрические параметры с условиями измерения, предельные эксплуатационные данные и описательные атрибуты (проводимость, корпус, технология, производитель, годы выпуска и др.). База - SQLite (UTF-8), с заделом на будущий перенос на PostgreSQL/MariaDB.

Наполнение двумя способами: импортом из структурированного файла (jsonc или yaml) или напрямую парсером обозначений.

## Возможности

- разбор обозначений: `КТ315Б`, `ГТ404А`, `2Т914А-1` (бескорпусное), `КТ825А1` (модификация), `1ТС801А` (сборка);
- 20 кодов электрических параметров (`h21e`, `FGran`, `KShum` с частотой, `PVyh`, `Kpd` и др.) с условиями и каноническими единицами;
- предельные данные, включая импульсные режимы, температуры и тепловое сопротивление;
- атрибуты: проводимость, корпус, цоколёвка, цветовая маркировка, ESD-чувствительность, военное исполнение, производители, годы выпуска;
- валидация и на уровне приложения, и на уровне БД (CHECK-ограничения), каскадное удаление, идемпотентный импорт.

## Быстрый старт

Требуется Go 1.27+ (зависимости `modernc.org/sqlite`, `tailscale/hujson`, `goccy/go-yaml` — pure Go, без cgo).

```shell
# сборка и проверка работоспособности
go run ./cmd/soviettransistors parse КТ315Б

# наполнение базы из файла с примерами (20 транзисторов)
go run ./cmd/soviettransistors import sample-data.jsonc

# просмотр
go run ./cmd/soviettransistors count
go run ./cmd/soviettransistors list
go run ./cmd/soviettransistors info КТ315Б
```

## Команды

| Команда | Назначение |
|---|---|
| `init` | создать таблицы (при командах записи — автоматически) |
| `import <файл.jsonc\|.yaml>` | импорт транзисторов со всеми данными (формат — по расширению: .jsonc/.json, .yaml/.yml) |
| `add <обозначение>...` | добавить транзисторы по обозначению (через парсер) |
| `parse <обозначение>...` | разобрать обозначение без обращения к базе |
| `list [фильтры]` | список обозначений; фильтры: `--material=Г`, `--subclass=П`, `--letters=АМ`, `--limit=N` и др. |
| `info <обозначение>` | полная карточка: атрибуты, параметры, предельные данные |
| `find <обозначение>` | проверить наличие по точному обозначению (при отсутствии — подсказка равнозначной по материалу записи) |
| `delete <обозначение>...` | удалить записи (каскадно с данными) |
| `count` | количество записей |

Общие опции: `--db <путь>` - файл базы (по умолчанию `./transistors.db` или переменная `TRANSISTOR_DB`), `--dry-run` - проверка без записи. Команды `list`, `info`, `find`, `count`, `delete` требуют существующую базу и не создают её.

Примеры:

```shell
go run ./cmd/soviettransistors add ГТ404А КП303Е
go run ./cmd/soviettransistors list --material=1 --subclass=Т
go run ./cmd/soviettransistors info 2Т914А-1
go run ./cmd/soviettransistors -- find 2Т312В
```

`find` - поиск по точному обозначению. Записи `КТ315Б` и `2Т315Б` раздельные (у каждой свои данные); при отсутствии точной записи выводится подсказка о равнозначной по материалу:

```text
$ go run ./cmd/soviettransistors find 2Т312В
Не найдено: 2Т312В
Есть равнозначная по материалу запись: КТ312В (символы Г/1, К/2, А/3, И/4 обозначают один материал, но записи раздельные)
```

`add` - добавление по обозначению: новые транзисторы, раздельная запись `2Т315Б` при существующем `КТ315Б`, дубликат и старая система «П...» (не поддерживается):

```text
$ go run ./cmd/soviettransistors add КТ361А 2Т315Б КТ315Б МП16А
МП16А: позиция 1: ожидался тип материала — Г или 1 (германий), К или 2 (кремний), А или 3 (арсенид галлия), И или 4 (индий), получено «М»
Добавлено: КТ361А
Добавлено: 2Т315Б
Пропущено (уже есть): КТ315Б
Итого: добавлено 2, пропущено 1, ошибок разбора 1
```

## Формат импорта (jsonc/yaml)

Корень - объект с массивом `transistors`. Запись - строка, объект с `name` или объект с явными полями обозначения. Секции `attributes`, `parameters`, `ratings` необязательны: отсутствует или `null` - не меняется, задана - заменяется целиком (`null` у поля внутри секции - «не задано», у `manufacturers` - «не менять список»). Те же данные можно писать в yaml (`.yaml`/`.yml`): структура и семантика идентичны, числа - без кавычек.

```jsonc
{
  "transistors": [
    // 1) только обозначение
    "КТ315А",

    // 2) полное описание
    {
      "name": "КТ315Б",
      "attributes": {
        "structure": "npn", "technology": "планарная",
        "package": "КТ-13", "packageMaterial": "пластик", "pinout": "КБЭ",
        "yearFrom": 1967, "yearTo": 1992,
        "manufacturers": ["Восход", "Терма"]
      },
      "parameters": [
        { "parameter": "h21e",  "min": 50, "max": 350, "Uke": 10, "Ik": 1 },
        { "parameter": "FGran", "min": 250, "Uke": 10, "Ik": 5 },
        // один параметр при двух температурах - две строки
        { "parameter": "Ikbo", "max": 0.5, "Ukb": 10, "temp": 25 },
        { "parameter": "Ikbo", "max": 5,   "Ukb": 10, "temp": 85 }
      ],
      "ratings": { "UkeMax": 20, "UkeoMax": 15, "IkMax": 100, "PkMax": 150, "tempMin": -60, "tempMax": 125 }
    },

    // 3) обозначение явными полями
    {
      "material": "Г", "subclass": "Т", "feature": 1,
      "number": 15, "letters": "А",
      "attributes": { "structure": "pnp" },
      "parameters": [
        // условия включения с общей базой: пара Ukb + Ie
        { "parameter": "h21e", "min": 30, "max": 90, "Ukb": 5, "Ie": 1 }
      ]
    },

    // 4) частотные параметры: freq обязательна
    {
      "name": "КТ3102А",
      "parameters": [
        // коэффициент шума: 1 кГц = 0.001 МГц, Rg - сопротивление генератора
        { "parameter": "KShum", "max": 10, "Uke": 5, "Ik": 0.2, "freq": 0.001, "Rg": 200 }
      ]
    },

    // 5) СВЧ-генераторные параметры и бескорпусное исполнение
    {
      "name": "2Т914А-1",
      "parameters": [
        { "parameter": "PVyh", "min": 3, "freq": 1000 },
        { "parameter": "Kpd",  "min": 40, "Uke": 15, "Ik": 100, "freq": 1000 }
      ],
      "ratings": { "UkeMax": 30, "IkMax": 300, "PkMax": 3000, "tempMin": -60, "tempMax": 125 }
    }
  ]
}
```

Полный справочник кодов параметров, правил условий, единиц измерения и полей секций:

```shell
go run ./cmd/soviettransistors help
```

а также файлы `sample-data.jsonc` / `sample-data.yaml` (полные примеры одной и той же выборки) и регламент `.kilo/skills/soviet-transistors-go/SKILL.md`.

## Сборка и публикация

```shell
# проверка
go build ./... && go vet ./... && go test ./... && gofmt -l .

# бинарник для текущей платформы
go build -o soviettransistors ./cmd/soviettransistors

# кросс-компиляция (pure Go, без cgo) — один статический бинарник без runtime-зависимостей
GOOS=windows GOARCH=amd64 go build -o soviettransistors.exe ./cmd/soviettransistors
GOOS=linux GOARCH=arm64 go build -o soviettransistors-arm64 ./cmd/soviettransistors
```

## Структура проекта

```
cmd/soviettransistors/   точка входа (main)
internal/domain/         обозначения, каталог параметров, ratings, атрибуты, валидация
internal/storage/        переносимое реляционное ядро на database/sql + SQLite-диалект (DDL)
internal/importer/       реестр форматов импорта (jsonc/json — hujson, yaml/yml — goccy/go-yaml), упорядоченный разбор, валидация секций
internal/cli/            разбор аргументов, команды, вывод, справка
```

Правила разработки — `AGENTS.md`; регламент наполнения — `.kilo/skills/soviet-transistors-go/SKILL.md`.
